# 设计原理与依据（thinking / thought skill）

这个 skill 不是技巧的随手拼凑。它的每一步背后都有理论或实证支撑。诚实起见，下面标注**证据强度**：有些是被反复验证的实证效应，有些是经大量实践检验但偏框架/启发式的东西——不把所有东西都包装成"科学"。

## 一、脊柱：三个母理论

整个循环几乎每一步，都是这三件事在反复起作用。

**1. 认知负荷理论（Cognitive Load Theory, Sweller）+ 工作记忆极限（Miller 7±2 / Cowan ~4 组块）**
工作记忆一次只能握住 3–4 个组块。"想不清"多半是**容量溢出**，不是智力问题。整个循环都在给工作记忆卸载：要么把内容外化到脑外，要么一次只做一个认知操作（→ 铁律"一次一问"）。

**2. 写作认知模型（Hayes–Flower, 1981）**
写作是**同时进行 计划/转译/审阅 三种操作**的问题求解，而三者抢占同一份工作记忆——这正是"通过写作思考很慢"的根因。一个人写作时被迫同时当作者、编辑、质疑者，所以卡。**本 skill 的加速机制：把"审阅/质疑"这个角色外包出去，让用户的大脑只跑"生成"。**

**3. 分布式/延展认知（Extended Mind, Clark & Chalmers；Hutchins）+ 元认知（Flavell）**
笔记、对话对象都是"脑外的思考器官"。用户 + 笔记 + 会追问的 AI = 一个比"独自一人"更大的认知系统。AI 在此扮演一个人最难对自己做的**元认知（监控自己在想什么、哪里没想清）**。

## 三、为什么"多轮慢逼近"优于"一次性梳理"

- **双系统（Kahneman）**：模糊念头是 System 1 的直觉产物，快而糊。每个具体问题都在**强制调用 System 2** 慢速核查。一次抛五问，System 2 扛不住会退回 System 1 挑最好答的——等于没追问。**一次一问 = 逼他每次只用 System 2 咬穿一个点。**
- **最近发展区 + 内化（Vygotsky）**：思维本质是"内化了的对话"（inner speech）。好的追问者（"更有知识的他者"）先把这套对话摆到用户面前，多轮之后他会**把这套追问内化成自己的**——用久了不靠 skill 也会自己这么问。这就是"辅助而非替代"的终极形态；一次性梳理给不了，因为他没经历过程。
- **生成效应（generation effect）**：自己生成的答案比被告知的记得牢、理解深。多轮里每句结论都由用户说出，所以卡片是"他的"。

## 四、复利：为什么产物是"常青原子卡 + 关联"

历史铁证：社会学家 Niklas Luhmann 用约 9 万张卡片盒（Zettelkasten）产出 70+ 本书、400+ 篇论文，并称这盒卡是他的"思考搭档"。谱系上三家：

- **Luhmann（原理）**：卡片盒能"生长"、能意外连出你没想到的联系，全部来自**链接而非分类**。
- **Sönke Ahrens《How to Take Smart Notes》（流程）**：闪念笔记 → 文献笔记 → **永久笔记**。用户每天的碎片=闪念笔记；卡片=永久笔记。/thought 模式就是这条"碎片→永久"的提炼管线。
- **Andy Matuschak「常青笔记」**：大多数笔记"写一次再不读"（write-once-read-never），是知识的坟墓。让卡片复利的**四属性**：
  1. **原子**：一卡一想法 → 才能被重组进多种语境。
  2. **概念导向 + 声明式标题**：标题是一个完整**主张**（不是话题）→ 让卡成为可被引用的"接口"。（本 skill 里"炼成一句话结论"就是这个标题。）
  3. **自己的话 + 自足**：半年后脱离上下文也读得懂（生成效应）。
  4. **密集链接 > 分类**：价值在连接里，不在卡里。

**关键**：复利不发生在写卡那一刻，而在**链接与再提取**那一刻。所以本 skill 收尾提供可选的关联步骤。但为了永不破坏已有知识库，采用**只读 + 单向链接（放在新卡底部）+ 需显式指令触发**的保守设计——最坏情况也只影响这一张新卡。

## 五、这个 skill 的"最小可行方案"取向

本 skill 的卡片比标准常青笔记多逼一步：**从"我想清了什么"逼到"下次遇到同类问题我会怎么做（一句话/流程/SOP）"**。因为可复用的**解法**比可复用的**观点**复利更快——它能被直接调用，而不只是被回忆。
