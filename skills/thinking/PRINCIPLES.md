# 设计原理与依据（thinking / thought）

这个 Skill 的目标不是证明每个步骤都“科学”，而是把有实证支持的认知机制与有用的哲学、决策框架组合成一套可检验流程。下面区分实证效应与启发式框架，不用名人权威替代论证。

## 一、六个基础机制

### 1. 认知卸载与工作记忆

复杂想法经常同时包含概念、例子、因果、情绪和行动，容易超过工作记忆容量。把原料外化后，由 AI 主动重建层级和关系，可以减少用户同时扮演“生成者、编辑、质疑者、结构师”的负担。

设计含义：一轮只推进一个核心认知目标，但不等于一轮只准提问；结构化反馈本身就是卸载。

### 2. 写作即问题求解

Hayes–Flower 写作认知模型把写作看作计划、转译、审阅之间的循环。用户表达混乱时，问题不一定只是措辞，而可能是计划结构、概念关系或审阅标准尚未形成。

设计含义：AI 不只承担“质疑者”，还承担临时的逻辑编辑与结构师，先交付候选结构，再由用户判断。

### 3. 分布式认知与脚手架

用户、对话、笔记和模型共同组成一个扩展认知系统。维果茨基式脚手架强调支持应让用户完成独自暂时做不到的认知动作，而不是只反复要求用户再努力一点。

设计含义：用户说“不知道”时，AI 提供少量可比较的候选；随着理解提高，再逐渐撤掉脚手架。

### 4. 生成效应与认知所有权

自己参与形成的结论更容易理解和记住，但“必须由用户逐字生成”不是生成效应的必要条件。用户可以通过选择、修改、反驳 AI 候选参与生成。

设计含义：区分用户原意、AI 推断、AI 候选与共同结论，既保留思想所有权，也允许真正协作。

### 5. 先诊断认知卡点，再选择干预

同一句“我想不清楚”可能来自缺少概念、信息过载、因果链缺口、对既定结论的保护、急于消除不确定，或缺少行动依据。直接调用一个通用模型，容易解决模型擅长的问题，而不是用户真正的问题。

设计含义：先判断当前对话状态和需要执行的认知动作，再选择一到两个模型。诊断只针对当前材料，不把暂时状态人格化。

### 6. 认知流畅性不等于真实性

结构完整、语言连贯会提高理解感和确信感，但 AI 同样能够为相反结论生成有说服力的解释。对话必须同时维护两种完整性：思想归属没有漂移，证据强度没有被语言拔高。

设计含义：把来源审计与证据审计分开；关键结论要标出事实、经历、推断、假设或价值选择，并用反例、外部事实或最小实验区分竞争性解释。

## 二、流程依据

| 步骤 | 主要依据 | 性质 |
|---|---|---|
| 收 | 自由写作、认知卸载、反映式倾听 | 外化有实证，具体流程为框架 |
| 架 | 组块、论证图、系统图、层级分解 | 认知与问题求解框架 |
| 诊 | 解释深度错觉、批判性思维、类别分析 | 部分实证 + 哲学/逻辑框架 |
| 补 | 脚手架、类比迁移、多模型思考 | 学习研究 + 启发式 |
| 辩 | 考虑相反面、证伪、反演、二阶效应 | 去偏见有实证，部分为决策框架 |
| 炼 | 组块、生成效应、压缩与外部表征 | 有实证支持 |
| 迁 | 迁移学习、案例推理、边界条件 | 迁移有实证，分类为设计框架 |
| 卡 | 常青笔记、原子笔记、检索与链接 | 知识管理实践框架 |

## 三、为什么“主动重构 + 选择性提问”优于连续追问

连续追问把大部分生成、归类和补缺工作留给用户。它适合用户已经拥有答案、只需被引出的情境，却不适合概念不足、层级混乱或存在未知变量的情境。

新版采用三个约束：

1. **每轮先产生认知增量**：新结构、具体诊断、候选解释或新版结论。
2. **问题只解除关键分叉**：答案不会改变整体结构时不问。
3. **连续提问设上限**：防止对话退化成低效率访谈。

这仍保留慢思考，但把用户的慢思考集中在判断、修正和取舍，而不是要求他独自完成全部加工。

## 四、思考镜头为什么是“动作”而不是“人格模仿”

维特根斯坦、亚里士多德、马斯克、纳瓦尔、芒格、达利欧代表的是不同问题上的有用认知动作，例如语言澄清、分类与原因、第一性原理、长期杠杆、反演与激励、经验到原则。

把它们写成名人角色会产生三个风险：刻板模仿、诉诸权威、一次堆入太多观点。因此 Skill 只编码可检查的动作，每轮最多调用两个，并让任何外部模型回到用户事实中接受验证。

模型选择采用两层路由：先确定需要压缩、区分、建图、补桥、扩维、校验还是落地，再选择能够完成该动作的具体镜头。这样可以吸收多元思维模型的价值，又避免“手里拿着模型，看什么都像它的应用场景”。

## 五、从经历到可修订知识

用户的生活与工作形成：

`经历 → 决定与行动 → 结果 → 反馈 → 候选解释/规则 → 再次检验 → 修订`

- **原则**回答在一类情境中优先如何行动或取舍。
- **思维模型**解释变量如何通过机制相互作用，并帮助预测和诊断。
- **方法论**规定为了重复达成结果要执行的步骤、检查点与调整条件。

一次经验只能支持候选。多次重复也可能只是同一个偏差反复发生，因此成熟度必须同时考虑反例、失败条件与修订记录。

## 六、为什么要先归核，再压缩

工作记忆一次能稳定处理的组块有限，知识卡因此必须删掉完整推演，只保留能够理解、判断和调用的内容。但压缩之前必须先找到用户思想的语义中心，否则越简洁，偏离得越彻底。

长段表达中的开头、结尾、反复主张和多个例子的共同不变量，比最详细的例子更能代表用户核心。例子默认只是应用证据，AI 补充默认只是候选解释。只有完成来源审计后，才能决定主卡是原则、思维模型还是方法论。

主卡默认不再保留长篇“原始想法（梳理版）”或完整分析，而是使用“一句话—问题—解决方案—逻辑—最小闭环”。这个顺序既帮助用户快速恢复当时的想法，也能直接成为口播或文章大纲。需要追溯时使用原笔记链接、1–3 句原始想法或单独的思考记录。这样做不是牺牲深度，而是把“形成结论”和“调用结论”分开。

最小可行行动必须形成一个可以立即运行的闭环：明确起点、相互衔接的动作、每步产物、最终反馈和完成信号。只有“建议做什么”而没有可检查结果，不算可复用知识。

费曼式表达要求先理解，再压缩成用户熟悉的场景、动作和因果。信息密度来自每句话都帮助理解或行动，而不是抽象名词更多。用户能用自己的话复述，才说明卡片真的降低了理解成本。
