# 卡片格式规格

## 卡片编号

每张卡都有编号，作为文件名前缀，永久不变（哪怕日后改标题，编号不改）。

- **主卡编号**：三位数字，从 `001` 起，全局递增。生成前用 Glob 扫描 `<vault_path>/<card_folder>/*.md`，取文件名开头能匹配 `^\d{3}` 的最大值 +1，零填充成三位；文件夹里没有任何编号卡时，从 `001` 开始。**不要自己维护计数器变量**——每次都以实际扫描结果为准，避免跨会话错乱。
- **副卡编号**：从某张主卡拆出的子卡，编号 = `{主卡编号}-{N}`，`N` 从 `1` 起递增（同一主卡拆出的第 1、2、3 张副卡分别是 `-1`、`-2`、`-3`）。副卡不占用主卡序列的号，也不单独扫描全局最大值。
- **编号冲突处理**：极少数并发情况下若扫描后编号已被占用，自动 +1 直到找到空位。

## 卡片规格（一卡一想法，原子）

- **文件名 = `{编号} {声明式标题}`**（标题＝用户的那句主张，去掉不能做文件名的字符）。例：`003 好好生活的前提，是把每天切成「深度 浅层 生活」三层，各归其位.md`；其副卡例：`003-1 深度写作提速法…….md`。
- 存到 `<vault_path>/<card_folder>/<编号> <标题>.md`。
- 模板：

```markdown
---
created: {YYYY-MM-DD}
card_id: {编号}
tags: [思考卡片]
source: thinking
status: complete
---

# {声明式标题＝主张/一句话结论}

**核心问题**
{这张卡只回答的那一个问题}

**最小可行方案**
{一句话 / 或分步流程 / 或 SOP——讨论中逼出来的解法}

---
> **思考留痕**
>
> **背景（为什么会有这个想法）**：{从用户输入里提取——他当初的处境、动机、痛点，用他的话}
>
> **思考过程（怎么一步步想清的）**：{把这次对话的推进提炼成几步——最初的模糊念头 → 关键修正 → 借鉴/正名 → 收敛，让他日后能看到自己的思考路径}
```

> **思考留痕不是原话堆砌**：要从用户的输入和整段对话里**提取**出"背景（为什么有这个想法）"和"思考过程（怎么一步步想清的）"，让他日后回看时知道当初为何这么想、是如何推演到结论的。用他的话，别加评判。

**frontmatter 字段说明**：
- `source`：`thinking`（/thinking 产出）或 `thought`（/thought 产出），用于区分卡片来源。
- `status`：`complete`（完整思考）或 `in-progress`（中途退出，见下）。

## 进行中卡片（用户中途退出时使用）

用户随时可以说"先到这""够了"等中止追问。AI 立即停止，用当前已有信息生成一张进行中卡片：

- frontmatter 中 `status: in-progress`
- 核心问题：填当前锚定的那个（若已过③锚）；否则填用户最初的模糊表述
- 最小可行方案：若已有则填；否则留空或写"待继续思考"
- 思考留痕：记录已推进到哪一步、卡在哪里

## 生成后

告诉用户存到了哪，并**多问一句**："要不要检索你的旧卡片，把相关的连接上来？（可以不做）"——只有他明确要，才执行关联步骤。

## 可选步骤：单向关联（安全优先，必须用户显式同意才做）

**默认不做。** 用户明确说"要连接/检索旧卡"时才执行：

1. **只读**扫描 `<vault_path>`（用 Grep/Glob 按核心问题、主张里的关键词检索 `.md` 文件）。
2. 从命中里挑 **3–5 条最匹配**的旧卡（相连 / 矛盾 / 互为特例）。
3. 把它们作为**单向链接**追加到**新卡最下方**：
   ```markdown

   ## 关联
   - [[旧卡标题A]] — {关系：延伸/矛盾/是其特例}
   - [[旧卡标题B]] — {关系}
   ```
4. **绝对不要**修改、删除、或给任何**已有**笔记添加内容——只碰这张新卡。不做双向链接。

> 为什么这样设计：复利发生在"链接"与"再提取"那一刻，不在写卡那一刻。但只读 + 单向 + 需指令触发，保证 skill 永不破坏已有知识库，最坏情况也只是这一张新卡。详见 [PRINCIPLES.md](PRINCIPLES.md) 的"复利"一节。

## 可选步骤：拆分副卡（安全优先，必须用户显式同意才做）

**默认不做。** 主卡生成后，若其中包含另一个够格独立的原子想法/方法（一卡一想法原则），可以问用户要不要拆出来。用户同意才做：

1. 副卡同样走"标题=主张、核心问题、最小可行方案、思考留痕"的规格，内容不是复制主卡，而是**这部分自己的**原子内容。
2. 编号按上面"副卡编号"规则：`{主卡编号}-{N}`。
3. 副卡与主卡**互相单向链接**（这一对属于同一次讨论产生，不算"碰旧笔记"，可以双向）：主卡的「关联」区加一条指向副卡，副卡的「关联」区加一条指回主卡。
4. 一次只拆一张，拆完确认后再问要不要继续拆下一张。

## 收尾

- 报告卡片路径（含编号）。
- 若拆了副卡，报告副卡编号与路径。
- 若做了关联，列出连了哪几张、什么关系。
- 不要额外总结长篇——卡片本身就是产物。
