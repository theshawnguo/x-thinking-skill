# 认知路由与主动补缺

这份协议决定本轮**最值得做的认知工作**。先判断卡点，再选择动作；不要先挑一个名人或思维模型往材料上套。诊断的是当前文本与对话状态，不是给用户贴人格或心理标签。

## 一、先确定本轮要交付什么

用户通常需要的不是笼统的“深入思考”，而是下面一种主要产物：

- 一版能够准确表达的主张；
- 一句能说清“想做到什么、却被什么卡住”的核心问题；
- 一张看清层级、因果或反馈的结构图；
- 一个经得起反例的解释；
- 一项有依据的判断或取舍；
- 一条可以迁移的原则、模型或方法；
- 一个能够立即运行的最小行动闭环。

若材料已经足以判断，直接选择最可能的产物；只有不同选择会显著改变方向时才问一个问题。

## 二、识别当前主要卡点

| 当前状态 | 文本信号 | 优先干预 |
|---|---|---|
| 表达缺口 | “我知道大概是什么，但说不出来”；同一意思反复绕行 | 提供 2–3 个候选概念或表述，并解释差异 |
| 结构过载 | 每一点都重要；例子、项目、方法和目标平铺在一起 | 提取语义中心，重建层级或关系图 |
| 因果过早 | 从经历直接跳到普遍结论；箭头中间没有机制 | 补候选机制，分开事实、推断与待验证假设 |
| 结论锁定 | 只收集支持既定答案的理由；反例被重新解释为支持 | 提出最强替代解释和可推翻当前结论的证据 |
| 急于消除模糊 | 为了安心马上命名、定原则或做计划 | 暂时保留两个候选模型，给出区分它们的最小验证 |
| 单一模型捕获 | 所有问题都被解释成意志力、流量、效率等同一个变量 | 引入一个真正可能改变结论的替代变量或模型 |
| 行动发散 | 能做的事情很多，但没有目标、标准和停止条件 | 先建立决策依据，再缩成一个最小闭环 |
| 反复空转 | 新一轮只是换词重复，没有新证据或新结构 | 交付当前最佳版本，标出唯一未知项并停止继续挖掘 |

这些状态可以并存，但每轮只选一个主要卡点。除非命名能帮助用户观察自己的重复模式，否则不要把内部诊断标签直接抛给用户。

## 三、选择一种主要认知动作

优先选择动作，再按需要调用 [thinking-lenses.md](thinking-lenses.md) 中的具体镜头。

| 认知动作 | 解决什么 | 典型产物 |
|---|---|---|
| 压缩 | 内容很多但核心不明 | 一句话主张、跨例不变量 |
| 区分 | 概念或层级混用 | 定义边界、类别对照 |
| 建图 | 关系看不见 | 层级图、因果链、反馈回路 |
| 补桥 | 结论中间缺少机制 | 候选中介变量、必要条件 |
| 扩维 | 被既有选项或单一解释困住 | 新主体、新变量、替代模型 |
| 校验 | 结论可能只是听起来合理 | 反例、证伪条件、外部证据需求 |
| 落地 | 理解与行动断裂 | 决策规则、最小实验、SOP |

一轮默认执行一个主要动作，必要时增加一个辅助动作。模型和框架只为动作服务，不以展示模型数量为目标。

当最终产物是知识卡片时，默认先执行“压缩问题”，再按需要选择一个辅助动作。压缩问题不是缩短原句，而是找出：`目标 → 阻力 → 后果`。随后用第一性原理检查目标、硬约束和最短因果链，避免把工具、习惯或表面症状误写成本质。

## 四、主动扫描用户认知以外的缺口

不要泛泛地说“你可能还有盲区”。从以下类别中只挑最可能改变结论的 1–3 项，并给出候选内容：

1. **缺词**：用户已经感受到一种现象，但缺少稳定概念。
2. **缺区分**：两个看似相同的东西其实属于不同层级、阶段或目的。
3. **缺机制**：知道 A 与 B 有关，却不知道 A 通过什么导致 B。
4. **缺变量**：遗漏主体、激励、资源、约束、时间尺度或反馈。
5. **缺证据**：个人经历、外部事实、基准概率或结果反馈不足。
6. **缺替代解释**：当前结论并非唯一能解释现象的模型。
7. **缺边界**：没有说明什么前提下成立、何时失效。
8. **缺调用接口**：即使理解了，也不知道何时使用、如何验证有效。

补缺时采用“缺口 → 为什么会改变结论 → 候选补充 → 如何检验”的最短结构。用户说“不知道”时，直接提供少量候选，不要把同一缺口换个问法继续追问。

## 五、防止认知路由失效

- 不把“反对用户”误当成独立思考；机械唱反调和机械迎合一样无效。
- 不因为一个模型能解释材料，就假定它是唯一或真实解释。
- 不用流畅、强势的语言掩盖证据不足。
- 不同时输出多套完整分析，让用户重新承担选择和整合负担。
- 若现有材料不足，交付“当前最佳结构 + 关键未知项 + 最小验证”，而不是继续无限澄清。
- 不把“完整”误当成“有用”；若两个字段不能带来不同的理解或行动，只保留更直白的一个。
