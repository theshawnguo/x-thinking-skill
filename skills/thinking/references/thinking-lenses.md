# 思考镜头

这些是受不同思想传统启发的**认知动作**，不是模仿名人的语气、人格或结论。根据问题选择一到两个镜头即可；若普通逻辑分析已经足够，不必点名任何人。

## 选择指南

| 何时调用 | 优先镜头 |
|---|---|
| 词语越解释越乱、问题可能来自语言 | 维特根斯坦 |
| 多个层级或原因混在一起 | 亚里士多德 |
| 被行业惯例和默认做法困住 | 第一性原理（马斯克） |
| 讨论个人事业、杠杆、长期生活方式 | 纳瓦尔 |
| 做决策、找风险、检查二阶后果 | 芒格 |
| 从经历与错误中沉淀个人规则 | 达利欧 |

## 维特根斯坦镜头：澄清语言，必要时消解伪问题

认知动作：

- 不急着问抽象定义，先看一个词在具体例子里如何使用。
- 检查同一个词是否承担了不同含义。
- 检查两个不同概念是否因为名字相近被合并。
- 判断困惑来自现实问题，还是来自语言把边界弄乱。

典型产出：候选用法差异、概念边界、被消解的问题。

## 亚里士多德镜头：分类、分层、找原因与目的

认知动作：

- 区分“它是什么”“由什么构成”“如何形成”“为了什么”。
- 把目的、原则、系统、方法和动作放回不同层级。
- 检查一个例子是定义、证据、类比还是特例。
- 找出必要条件与充分条件，避免把相关性当成本质。

典型产出：层级图、类别区别、原因结构、目的—手段关系。

## 第一性原理镜头（马斯克）：拆掉继承假设，找到硬约束

认知动作：

- 把“大家都这样做”与真正不可违反的事实分开。
- 从目标、资源、约束和基本组成重新推导方案。
- 追问哪些步骤可以删除、合并或被系统承担。
- 区分真实约束与习惯性约束。

典型产出：最小必要结构、关键约束、被删除的默认前提。

## 纳瓦尔镜头：长期、杠杆与生活方式一致性

认知动作：

- 检查行动是否积累独特知识、声誉、产品或受众等长期资产。
- 区分出售时间与可以重复复制的杠杆。
- 检查事业是否嵌入想要的生活，而非长期破坏生活。
- 思考如何把个人独特能力产品化，而不是追逐通用竞争。

典型产出：复利资产、杠杆点、生活—事业一致性、长期游戏。

## 芒格镜头：多模型、反演、激励与二阶后果

认知动作：

- 先问“怎样一定会失败”，再反推避免条件。
- 检查参与者的激励，而不只听表面理由。
- 比较机会成本：选择它意味着放弃什么。
- 推演下一步之后还会发生什么。
- 用另一个学科模型检查同一问题，避免单一解释。

典型产出：失败清单、激励地图、机会成本、二阶影响。

## 达利欧镜头：经验反馈与可修订原则

认知动作：

- 从具体事件、决定、结果和错误中寻找重复模式。
- 把规则写成“情境—行动—机制—边界”，而不是口号。
- 区分一次经验、重复证据和已经稳定使用的原则。
- 为原则保留失败记录和修订条件。

典型产出：候选原则、证据等级、反例与修订接口。

## 使用护栏

- 不说“某某一定会怎么想”，只说“用这个镜头看，可能会注意到……”。
- 不用名人身份替代论证；任何候选仍要回到用户事实和情境。
- 不一次调用全部镜头。模型越多不等于越清晰。
- 外部补充必须标为候选，不能冒充用户已经形成的认知。
