# thought — 消化过去的碎片

`/thinking` 处理**当下一个**模糊念头；`/thought` 处理**过去攒下的一堆**碎片笔记（闪念笔记）。目标一样：沉淀成可复利的原子卡。理论依据（含"闪念→永久"提炼管线）见 [../thinking/PRINCIPLES.md](../thinking/PRINCIPLES.md)。

## 复用引擎

配置检查（`~/.claude/thinking-config.json`）、四条铁律、澄清循环（倒/镜/锚/凿/分/炼/卡）、卡片规格、可选单向关联——**全部与 thinking 相同**。开始前先读一遍 `~/.claude/skills/thinking/SKILL.md` 并遵循，本文件只描述**前置的"消化"步骤**。

## 本模式独有：先消化，再进循环

1. **拿到碎片**：用户可能粘贴一堆文本、给一个/多个 `.md` 文件、或一个文件夹路径。若是路径，用 Glob/Read **只读**取回内容。
2. **聚类**：把这些碎片按主题归拢，找出：
   - **反复出现的主题**（他其实一直在想的东西）
   - **内在的矛盾/张力**（两条笔记互相打架的地方——这里往往藏着最值得想清的问题）
3. **反馈全景**（一次性给他看，帮他从外部看见自己）：用他的话列出「几个主题簇 + 哪几处在打架」。
4. **让他挑一个**——只问一句："这里面，你现在最想想清楚哪一个？"（一次只深入一个，别贪多）
5. **进入澄清循环**：拿着他选的那簇碎片，走 thinking 的循环（从 ②镜 或 ③锚 切入通常更快，因为碎片已经是"倒"出来的原料）。**铁律照旧：一次一问、不替他写结论、用他的话。**
6. **成卡 + 可选关联**：与 thinking 完全一致。

## 注意

- 聚类只是帮他**看见**，不是替他下结论。哪些算一簇、哪个最重要，最终由用户拍板。
- **只读**这些旧笔记，绝不修改/删除原文件。
- 一次 `/thought` 通常只产出**一张**卡（深入一个问题）。想再消化下一个主题，再跑一轮。
